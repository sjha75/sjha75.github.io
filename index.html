Projects

NYU Courant

First-Order Trajectory Matching

Predicting chaotic and turbulent systems means running large ensembles, and each simulation is expensive. FTM learns a generative surrogate straight from trajectory data that advances the whole ensemble with a single network evaluation per time step. On 2D turbulence, it is both faster and more accurate than diffusion-based surrogates.

Paper · Code

NYU Courant

Solver2System

Solver2System tests whether LLMs can recognize when scientific simulation code is physically wrong. It pairs 32 PDE solvers with their equations, trajectories, and plain-language descriptions, along with versions containing planted physical bugs. We use it to evaluate whether models can catch and diagnose these errors, both by reading the code and by running it.

Paper

Georgia Tech

Stable High-Order Moment Closures

Moment closures approximate a stochastic system by tracking just a few of its statistics, but higher-order closures tend to blow up. I developed stabilization techniques, based on semidefinite programming and damping of higher-order cumulants, that keep closures stable up to 12th order and track reference solutions better than the standard Gaussian closure.
